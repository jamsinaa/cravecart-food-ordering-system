# CraveCart – Food Ordering Web Application

CraveCart is a Django-based food ordering web application where users can browse restaurants, view menus, add food items to a cart, and place orders.

## Features

- User Signup and Login
- Browse Restaurants
- Restaurant Menu Pages
- Add to Cart System
- Increase / Decrease Quantity
- Cart Total Calculation
- Checkout Page
- Order History (My Orders)
- Restaurant Search
- Admin Panel to Manage Restaurants and Menu

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite Database

## How the System Works

1. User creates an account or logs in.
2. User browses restaurants on the homepage.
3. User selects a restaurant and views its menu.
4. Food items can be added to the cart.
5. Cart page shows selected items and total price.
6. User proceeds to checkout and places the order.
7. Orders appear in the **My Orders** page.

## Admin Features

Using Django Admin, the administrator can:

- Add restaurants
- Add menu items
- Upload food images
- Manage orders
